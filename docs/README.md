# LEVEL 30

Квест на 30 дней: 16 сентября — 15 октября 2026.

Распакуйте ZIP и загрузите его содержимое в корень репозитория GitHub.
Главная страница — `index.html`. Сборка и установка зависимостей не нужны.
Для запуска на компьютере откройте `index.html` в браузере.

Вес можно вводить с запятой или точкой: `92,5` и `92.5`.

Прогресс сохраняется в браузере, а не в репозитории. При переходе на другой
адрес или устройство сначала экспортируйте JSON в разделе «Данные»,
а затем импортируйте его в новой версии. Персональные записи в архив не включены.
