LEVEL 30 — как открыть на iPhone

Файл index.html — это полностью автономный сайт без внешних библиотек.
Старт программы зафиксирован: 13 сентября 2026 в 08:00.

ВАЖНО ПРО SAFARI
ChatGPT не может сам опубликовать постоянный публичный интернет-адрес.
Ссылка внутри чата ведёт на файл, а не на размещённый в интернете сайт.

Самый удобный вариант для iPhone:
1. Скачайте папку/ZIP на компьютер или iPhone.
2. Разместите index.html на любом статическом хостинге (например, Netlify Drop, GitHub Pages, Cloudflare Pages).
3. Откройте выданный HTTPS-адрес в Safari.
4. Safari → Поделиться → «На экран Домой».
После этого LEVEL 30 будет ощущаться почти как приложение.

Если открыть файл локально, Safari/iOS иногда показывает его через «Файлы»/Quick Look,
а сохранение localStorage может вести себя менее стабильно. Поэтому внутри есть экспорт JSON.
